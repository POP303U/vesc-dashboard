# Custom RT-Data Dashboard

Implements a much better dashboard than the stock RT-Data view in vesc-tool.

## Features

- One main gauge and six small ones, in landscape and portrait, all customizable for different use cases.
- Custom battery bar design inspired by: https://vesc-project.com/node/3641
- Gauges emulate the original as best as possible to retain the vesc look.

## Notes

- Settings reset on restart (for now)
- Needs firmware 6.x
